# jingwenw15.github.io

Minimal Astro scaffold for a GitHub Pages personal website.

## Routes

- `/` — About
- `/work` — Work
- `/education` — Education
- `/fun-stuff` — Fun Stuff

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content editing

Update placeholder content in `src/data/site.js`.
